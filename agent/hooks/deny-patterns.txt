# Bash commands the agent may not run, one RE2 regex per line. Blank lines and
# #-comments are ignored. Matched case-insensitively against the whole command
# string.
#
# Rendered at install against the layout, so an operator who moved the config
# and the store gets rules naming where they are. Interpolated paths go through
# regexQuote. The guard's built-in fallback carries the compiled defaults.
#
# Not the security boundary, the agent uid being unable to read the key material
# regardless, but a corrective message naming faramir_run instead of an EACCES,
# and no encrypted blobs in the context window. See docs/design.md.
#
# It names credential disclosure plus writes to the paths that are the broker
# itself. It is not a general destruction guard.
#
# Two limits: a pattern matches the command string, so a grep or a heredoc that
# only mentions the text is refused like one that would run it; and "[^|]*"
# rather than ".*" wherever a rule spans arguments, so it stops at the first
# pipe.

# Direct decryption of the secret store
ansible-vault\s+(view|decrypt|edit|rekey)
\bsops\s+(decrypt|-d|--decrypt|-i\s+.*-d)
# Writing the store is the operator's, like reading it.
\bsops\s+(-e|--encrypt|encrypt|set|unset|rotate|updatekeys)\b
\bage\s+(-d|--decrypt)
# Bare age-keygen prints a private key; "-o FILE" writes it 0400 instead.
\bage-keygen\b(\s+-\S+)*\s*$
\bop\s+read\b
\bpass\s+show\b
\bgopass\s+show\b
\bvault\s+(read|kv\s+get)\b

# No rule for a wholesale environment dump. In an enrolled tree the command is
# rewritten before it runs, so `printenv` comes back with every managed value
# replaced by its token, which covers the case a pattern was for and covers it
# whatever printed it. What a pattern would add is the operator's own exported
# credentials, which faramir does not manage and cannot know the names of, and
# it would add nothing at all in a tree that was never enrolled, where no hook
# runs to apply it. A credential that must not reach this shell belongs outside
# the environment the agent inherits.

# Reading, writing or redirecting over anything this install protects.
#
# GENERATED from internal/install/protectedpaths.go, which is the same set the
# agents' own deny rules are rendered from: this install's directories at the
# paths this host uses, every file a [[secret.link]] or [[secret.refuse]] entry
# names, and every pattern one declares. A rule that refused an agent's file
# tools and said nothing about `cat` covered half of what an operator declaring
# a path would assume, so the two entry points are spelled from one list.
#
# The tool lists are internal/denyrules', and internal/guard builds the same
# three rules at run time for a config directory a rendered file did not name.
# Readers carry interpreters and copiers as well as pagers. "sed" is a writer
# only, and "grep" is neither, so naming a file in a search is not refused.
{{range commandRules .}}{{.}}
{{end}}
# The broker's own key by path, not left to the config directory: `--ssh-key`
# may put it anywhere, and one placed outside that directory matches nothing
# above.
{{if .SSHKey}}\b(?-i:cat|less|more|head|tail|bat|xxd|od|strings|base64|base32|hexdump|uuencode|rev|tac|awk|cut|nl|dd|jq|yq|python3?|perl|ruby|tee|cp|tar|scp|rsync)\b[^|]*{{.SSHKey | regexQuote}}
{{end}}
# The binary, named as one path rather than as its directory, or installing any
# unrelated tool into {{.BinDir}} would be refused.
\b(?-i:rm|shred|truncate|mv|cp|tee|dd|sed|chmod|chown|chgrp|setfacl|ln)\b[^|]*{{.BinDir | regexQuote}}/faramir\b
>\s*\S*{{.BinDir | regexQuote}}/faramir\b

# The plugin and extension an enrolment installs, which are faramir's own files
# rather than shared ones: init-project overwrites each in full on every run, so
# an edit here is discarded rather than kept, and what a removal buys in the
# meantime is an agent whose commands stop being routed through the guard.
#
# The merged files are deliberately absent: .claude/settings.json, .mcp.json,
# opencode.json, kilo.json and .agents/mcp_config.json carry the operator's own
# settings and other tools' servers beside faramir's entries, which is why
# init-project merges into them instead of replacing them. Editing those is
# ordinary work. What covers them instead is `faramir doctor`, which reports a
# registration that went missing, and the rule in the credentials section
# against removing faramir's own entries from a file you are otherwise free to
# change.
\b(?-i:rm|shred|truncate|mv|cp|tee|dd|sed|chmod|chown|chgrp|setfacl|ln)\b[^|]*(\.opencode/plugins/faramir\.js|\.kilo/plugin/faramir\.js|\.pi/extensions/faramir\.ts)
>\s*\S*(\.opencode/plugins/faramir\.js|\.kilo/plugin/faramir\.js|\.pi/extensions/faramir\.ts)

# Reaching the broker's private state. Reading the audit log is covered above;
# listing the directory is not. journalctl is absent: the daemons log ref names
# and counts, never values.
#
# faramir under sudo, whichever subcommand: the daemons, the internal helpers,
# the escalation channel and every provisioning command at once. Nothing an
# agent may run needs root -- run, redact, status and `refs` all answer as
# the agent's own account -- so a sudo here is either a daemon, a decision that
# is the operator's, or a change to the install. Only sudo's own flags may
# precede the name. Managing a unit is not this, so "systemctl restart
# faramir-keeper" stays allowed; journalctl likewise, the daemons logging ref
# names and counts and never values.
\bsudo\b(\s+-\S+)*\s+faramir\b
# The same commands unprivileged. They act on the install rather than through
# it, so they are the operator's whether or not sudo is in front: refused here so
# the agent is told that, rather than meeting a permission error it will try to
# work around.
\bfaramir[-\s]+(init|init-project|vault[ \t]+add|vault[ \t]+edit|vault[ \t]+ls|vault[ \t]+rm|recipient[ \t]+add|recipient[ \t]+rm|recipient[ \t]+ls|recipient[ \t]+reseal|link[ \t]+add|link[ \t]+rm|link[ \t]+ls|refuse[ \t]+add|refuse[ \t]+rm|refuse[ \t]+ls|logs|escalations|approve|deny|doctor|reload|uninstall)\b
\bsudo\b.*-u\s+faramir
\bsystemctl\b.*\b(stop|disable|mask|kill|edit)\b.*\bfaramir-
